The policy

Every action below traces to one of these rules — nothing here is a black-box decision.

Rule ID Condition Action Stopping rule
R-STOP-MAX-RETRY retry_count_so_far >= 2 and vector != 'b2b_receivables' escalate_to_human_review TERMINAL: Auto-retry execution halted; dossier forwarded to Merchant Ops queue.
R-STOP-HARD-DECLINE failure_type == 'issuer_decline_hard' do_not_retry_flag_unrecoverable TERMINAL: Card fingerprint permanently suppressed from recovery pipeline.
R-FRAUD-VELOCITY failure_type == 'duplicate_suspicious_pattern' escalate_to_human_review HALTED: Immediate quarantine; bypasses automated recovery to protect chargeback ratio.
R-NET-IMMEDIATE failure_type == 'network_timeout' and retry_count_so_far < 2 auto_retry_now Max 1 immediate retry; abort if unacknowledged.
R-SOFT-DELAY-1H failure_type == 'issuer_decline_soft' and retry_count_so_far < 2 auto_retry_delayed_1hr Schedule 1 delayed run; abort if retry_count >= 2.
R-FUNDS-DELAY-24H failure_type == 'insufficient_funds' and retry_count_so_far < 1 auto_retry_delayed_24hr Single delayed window only; escalate if balance remains insufficient.
R-ABANDON-NUDGE failure_type == 'checkout_abandoned_fresh' send_hinglish_nudge_with_discount Single nudge policy; no follow-up spam allowed.
R-ABANDON-STANDARD failure_type == 'checkout_abandoned_aged' send_recovery_link_standard Standard link lifetime 7 days.
R-MANDATE-RENEW failure_type == 'upi_mandate_expired' send_mandate_renewal_link Link expires in 72h; fallback to invoice cancellation if unfulfilled.
R-CARD-TOKEN-REAUTH failure_type == 'card_recurring_token_revoked' send_card_reauth_link Link lifetime 48 hours.
R-B2B-PTP-PAUSE failure_type == 'invoice_overdue_60d_ptp_active' or ptp_status == 'active' pause_recovery_ptp_active PAUSED: Automatic dunning suppressed until commitment date passes.
R-B2B-CHASER-30D failure_type == 'invoice_overdue_30d' send_b2b_receivables_chaser Dunning cycle 1 of 3.
R-B2B-LEGAL-ESCALATE failure_type == 'invoice_overdue_90d_default' escalate_to_finance_collections TERMINAL: Automated actions halted; legal collections initiated.
